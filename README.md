# Taskbar Jump List Copy PID

A Windhawk mod that adds a "Copy PID" item to the jump list shown when you right-click a taskbar button on Windows 11. Clicking it copies the process ID of the app to the clipboard. If the app has windows in several processes, all of their PIDs are copied, separated by commas.

## Install

1. Install [Windhawk](https://windhawk.net/).
2. Open Windhawk and go to the "Mods" tab.
3. Click "Install from file" (or create a new mod and paste the contents of `taskbar-jump-list-copy-pid.wh.cpp`).
4. Enable the mod.

## Remove

Disable or uninstall the mod from the Windhawk "Mods" tab. No system files are changed.
